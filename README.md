# 🍔 Nyam.AI - Real-Time Food Marketplace Ecosystem

Nyam.AI is a modern food marketplace platform that connects buyers and sellers in one interactive ecosystem. The app is designed with a focus on premium user experience, real-time data synchronization, and efficient order management.

## ✨ Key Features

### 🛒 For Buyers (Buyer Portal)
- **High-Fidelity UI/UX**: Modern design with smooth animations and a responsive interface.
- **Smart Shopping Cart**: Dynamic shopping cart system with automatic shipping cost calculations.
- **Real-Time Chat**: Communicate directly with sellers to inquire about products or availability.
- **Order Tracking & Receipt**: Complete order history with aesthetically pleasing digital receipts.
- **Star Rating System**: Provides experience ratings after an order is completed.

### 🏪 For Sellers (Seller Dashboard)
- **Live Buyer Activity**: Monitor buyer activity in real-time (as they add/remove items from their cart).
- **Order Management Panel**: Receive and manage incoming orders with a "Ding" sound notification.
- **Catalog Management**: Add, edit, or delete products with image and video upload support (via Cloudinary).
- **Interactive Chat Hub**: Interact with multiple buyers efficiently through a centralized chat panel.

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+).
- **Backend**: PHP 7.4+ (REST API Gateway).
- **Database**: MySQL.
- **Real-Time Engine**: Long-Polling Synchronization with Timestamp Cursor system.
- Media Hosting: Cloudinary API integration for product image and video assets.
- Architecture: Supabase-style polyfill for seamless database interaction in PHP environments.
